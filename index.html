PARTE 1

Estructuración con Tablas HTML

Semántica de Datos

Las tablas HTML se deben utilizar únicamente para representar datos tabulares (filas y columnas). Nunca se deben emplear para maquetar la estructura o rejilla de un sitio web.

  • ✔ <thead>: Agrupa el contenido del encabezado.
  • ✔ <tbody>: Agrupa el cuerpo de la información principal.
  • ✔ <tfoot>: Agrupa el pie de tabla (totales, resúmenes).
  • ✔ colspan y rowspan: Atributos para expandir columnas y filas.
Sintaxis Básica
<table class="w-full">
  <thead>
    <tr>
      <th>Producto</th> <th>Precio</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>Laptop Core i7</td> <td>S/. 2500</td>
    </tr>
  </tbody>
</table>
Consejo SEO: Usar <caption> mejora la accesibilidad del lector de pantalla. Estándar W3C

Reporte Ventas Complejo (Fusión)

El diseño de reportes corporativos complejos requiere un control perfecto sobre los atributos de agrupación o expansión de celdas:

PARTE 2

Formularios y Capturas

Interactividad

El elemento contenedor clave es <form>, responsable de coordinar el procesamiento o envío de datos mediante los atributos primordiales: action y method.

  • ✓ <label>: El rotulado descriptivo para mayor accesibilidad (usa for).
  • ✓ <input>: El control interactivo determinado por el atributo type.
  • ✓ Atributo name: Envía un identificador clave-valor hacia el back-end.
  • ✓ Atributo required: Realiza validaciones del lado del cliente.
Sintaxis Básica
<form action="/guardar.php" method="POST">
  <label for="txtNombre">Nombres:</label>
  <input 
    type="text" 
    id="txtNombre" 
    name="usuario" 
    required>
  <button type="submit">Enviar</button>
</form>
Consejo de Usabilidad: Vincular etiquetas con inputs agiliza las pulsaciones en pantallas de dispositivos móviles. UX Web
EJEMPLO 3

Formulario de Registro Básico

Un formulario clásico de registro de usuarios utiliza componentes de captura estandarizados que facilitan una recolección rápida de datos.

text Ideal para textos estándar de una línea (nombres, apellidos).
email Valida de forma nativa la sintaxis básica (@dominio).
password Enmascara los caracteres ingresados para resguardar la privacidad.
Vista Previa Interactiva 
<form class="space-y-3">
  <div>
    <label for="name">Nombres:</label>
    <input type="text" id="name" required>
  </div>
  <div>
    <label for="email">Correo:</label>
    <input type="email" id="email" required>
  </div>
  <button type="submit">Registrar</button>
</form>
EJEMPLO 4

Formulario de Valoración y Feedback

Los formularios robustos van más allá de cajas de texto simples. La inclusión de listas de selección estructuradas y bloques multilínea agilizan la recolección de opiniones.

<select> + <option>: Ofrece menús desplegables cerrados, evitando errores de tipeo y estructurando los datos enviados al servidor.
<textarea>: Caja multilínea pensada para recolectar opiniones detalladas, reclamos o sugerencias del alumnado.
Vista Previa Interactiva 
<form>
  <label for="curso">Curso:</label>
  <select id="curso">
    <option>Desarrollo Web</option>
    <option>Bases de Datos</option>
  </select>

  <label for="coment">Comentarios:</label>
  <textarea id="coment"></textarea>
  
  <button>Enviar</button>
</form>
